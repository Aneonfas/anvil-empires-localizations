# Русификатор Anvil Empires

[Выбор языка](README.md) · [Español](README.es.md) · [Сообщить о проблеме](https://github.com/Aneonfas/anvil-empires-localizations/issues)

## Перед установкой

- Нужна установленная легальная копия Anvil Empires Pre-Alpha в Steam на Windows. Steam App ID игры — `2383950`.
- Сверьте **Steam build 24805551**, как описано ниже. Номер версии в игровом меню может отличаться: сравнивайте именно Build ID.
- Язык игры в Steam должен быть **English**, даже когда нужен русский перевод.
- Полностью закройте игру перед установкой, обновлением, переключением языка или удалением. Дождитесь окончания загрузок и обновлений игры в Steam.
- Активным должен быть **только один языковой PAK**. Не изменяйте, не переименовывайте и не удаляйте штатный файл `Anvil-Windows.pak` или незнакомые файлы модификаций.

### Как узнать Steam build

Это проверка текстового файла Steam. Ничего в нём менять или сохранять не нужно.

1. В библиотеке Steam нажмите правой кнопкой на Anvil Empires и выберите **Управление → Просмотреть локальные файлы**.
2. Откроется папка игры. В адресной строке Проводника найдите папку `steamapps`: обычный путь имеет вид `…\steamapps\common\папка игры`. Перейдите в `steamapps`, на два уровня выше папки игры.
3. Найдите в ней **`appmanifest_2383950.acf`**. Откройте его через **Открыть с помощью → Блокнот**.
4. Нажмите **Ctrl+F**, найдите **`"buildid"`** и прочитайте число справа. Например:

   ```text
   "buildid"    "24805551"
   ```

5. Для этого выпуска число должно быть **24805551**. Закройте Блокнот **без сохранения**.

Не используйте вместо него `appid`, `TargetBuildID` или номер из меню игры. Если файл не найден, число отсутствует либо Steam ещё обновляет игру, пока не устанавливайте пакет: завершите обновление и повторите проверку. Не исправляйте число вручную — это не меняет сборку игры.

### Как выбрать English

1. В библиотеке Steam нажмите правой кнопкой на игру и откройте **Свойства**.
2. Найдите настройку **Язык** игры и выберите **English / Английский**. В зависимости от версии Steam она может быть отдельной вкладкой или находиться в разделе **Общие**.
3. Если Steam начал загрузку файлов, дождитесь её окончания и снова проверьте Build ID.

Язык интерфейса самого Steam менять не требуется. Если выбора языка нет, не меняйте файлы игры наугад: проверьте [справку Steam о языках](https://help.steampowered.com/ru/faqs/view/4984-C127-121D-B3F2) или обратитесь в [поддержку перевода](https://github.com/Aneonfas/anvil-empires-localizations/issues).

## Установка вручную

Если пакет уже установлен через Hub, используйте управление в Hub; ручная замена может оставить в нём устаревшие сведения. Для временного отключения при ошибке Hub есть [отдельная инструкция](#nfg-hub).

1. Проверьте сборку и English по шагам выше. **Если build другой, остановитесь и дождитесь совместимого выпуска.**
2. Скачайте ZIP по ссылке в начале страницы и распакуйте его в отдельную папку.
3. Закройте Anvil Empires. Через Steam откройте локальные файлы игры, затем папку **`Anvil\Content\Paks`**.
4. Включите в Проводнике отображение расширений имён файлов. Если уже есть **`Anvil-Russian-Full_P.pak`** или **`Anvil-Spanish-Full_P.pak`**, отключите прежний перевод **до** копирования нового: переименуйте его так, чтобы имя больше не заканчивалось на `.pak`. Например, `Anvil-Russian-Full_P.pak` → `Anvil-Russian-Full_P.pak.disabled`.
5. Не перезаписывайте существующую резервную копию. Если такое имя занято, используйте другое, например `Anvil-Russian-Full_P.pak.backup-2.disabled`. Если старый перевод имеет другое имя, найдите его по инструкции того пакета; не отключайте незнакомые PAK наугад.
6. Скопируйте **только `Anvil-Russian-Full_P.pak`** из распакованного архива в `Anvil\Content\Paks`. В этой папке не должно остаться второго активного языкового PAK. Файлы других модификаций не трогайте.
7. Запустите игру через Steam. Проверьте главное меню и привычное игровое окно. Если перевод не появился или возникла ошибка, воспользуйтесь разделом [«Если что-то не работает»](#если-что-то-не-работает).

**`Anvil-Windows.pak` — штатный файл игры, его трогать нельзя.** Для установки не нужно заменять его, копировать весь ZIP в игру или запускать дополнительные программы.

## Обновление, смена языка и возврат назад

### Обновление или смена языка

Сначала проверьте Build ID и совместимость **нового** пакета. Затем повторите ручную установку: закрыть игру → отключить прежний языковой PAK → сохранить его под незанятым именем → скопировать новый. Если установкой управляет Hub, используйте его после ознакомления с ограничениями ниже.

**Испанский выпуск 0.1.0 рассчитан на build 24619810; он не является заменой RU 1.0.2 на build 24805551.** Не обходите предупреждение о несовпадении сборки ради смены языка. Проверяйте [страницу испанского перевода](README.es.md) и ждите совместимого выпуска.

После обновления самой игры временно отключите перевод, если Build ID изменился. Включайте его снова только после подтверждения совместимости опубликованного выпуска.

### Отключение или удаление

Для ручной установки закройте игру и переименуйте **`Anvil-Russian-Full_P.pak`** в имя с окончанием `.disabled`, не перезаписывая резервную копию. Это обратимо и возвращает игру к исходным текстам, если других языковых PAK нет. Если перевод больше не нужен, можно удалить **только этот файл перевода**; остальные файлы игры оставьте на месте.

Если пакет установлен через Hub, штатное удаление выполняйте в Hub. Ручное переименование отключает перевод, но **не удаляет его запись из Hub**.

### Возврат к сохранённому пакету

1. Убедитесь, что сохранённая версия совместима с **нынешним** Steam build. Старый перевод не возвращает старую версию игры.
2. Закройте игру. Отключите текущий языковой PAK, сохранив его под другим незанятым именем с окончанием `.disabled`.
3. У нужной резервной копии восстановите исходное имя, например `Anvil-Russian-Full_P.pak`. Убедитесь, что активен только один перевод, и запустите игру.

Если совместимой резервной копии нет, оставьте перевод отключённым. [Ранние русские выпуски](https://github.com/nullith2/anvil-empires-russian/releases) доступны по старому адресу; их Build ID также должен совпадать с вашим.

## NFG Hub

[Релиз NFG Hub 0.3.0](https://github.com/Aneonfas/nfg-hub/releases/tag/v0.3.0) · [Скачать Hub для Windows x64 — ZIP](https://github.com/Aneonfas/nfg-hub/releases/download/v0.3.0/NFG-Hub-v0.3.0-win-x64.zip)

Hub предлагает общую карточку локализаций Anvil Empires и выбор языка. До установки всё равно сверяйте сборку игры с выбранным выпуском. Если они различаются, **не продолжайте установку**.

**Известные ограничения опубликованного Hub 0.3.0, проверено 27.08.2026:**

- При переходе со старого русификатора, установленного вручную, на испанский Hub может оставить прежний русский PAK и не показать конфликт. Перед сменой языка закройте игру и самостоятельно отключите известный старый языковой PAK, как в инструкции выше. Само переключение допустимо только при совместимой сборке игры.
- Удаление иногда требует сеть и может завершиться ошибкой без неё. Для временного возврата к исходным текстам закройте игру и переименуйте **только установленный языковой PAK** в имя с окончанием `.disabled`, не перезаписывая копии. После восстановления сети завершите удаление в Hub. До этого его запись об установке может сохраняться; не удаляйте базы или служебные файлы Hub вручную.

Исправление этих ограничений пока не опубликовано. Проверяйте [релизы Hub](https://github.com/Aneonfas/nfg-hub/releases) перед обновлением; локальная разработка не означает доступный выпуск.

## Если что-то не работает

| Что произошло | Что проверить |
| --- | --- |
| Всё осталось на английском | Совпадает ли Build ID, выбран ли English, лежит ли `Anvil-Russian-Full_P.pak` непосредственно в `Anvil\Content\Paks`, а не во вложенной папке; не осталось ли второго языкового PAK. |
| Смешались русский и испанский | Закройте игру и отключите прежний известный языковой PAK. Оставьте один пакет, совместимый с вашей сборкой. |
| Появились квадраты или текст не помещается | Проверьте, что установлена нужная версия и нет старого языкового PAK. Сравните контрольную сумму ниже. Сохраните скриншот проблемного окна. |
| Игра перестала запускаться | Закройте игру и временно отключите только языковой PAK. Если ошибка остаётся без перевода, используйте проверку целостности файлов в Steam. Не удаляйте `Anvil-Windows.pak`. |
| Игра обновилась, build изменился | Оставьте перевод отключённым до совместимого опубликованного выпуска. |
| Hub не может удалить пакет без сети | Используйте временное отключение из [раздела Hub](#nfg-hub), затем завершите удаление через Hub при доступной сети. |

В перевод включены 2 984 записи выбранного каталога; это не означает перевод каждого текста игры. Серверные сообщения, надписи внутри изображений и некоторые редкие строки могут остаться английскими. Отдельные форматы чисел, дат и множественного числа следуют английским правилам. Проверка в игре была выборочной, а не проверкой каждого окна.

### Проверка скачанного файла

В папке с распакованным PAK можно открыть PowerShell и выполнить команду, которая **только читает файл**:

```powershell
Get-FileHash .\Anvil-Russian-Full_P.pak -Algorithm SHA256
```

Ожидаемый SHA-256 PAK для RU 1.0.2:

```text
ca869815134dbb65f5bea6fb5687e340524b586633a5921f6665531d27acbf98
```

Если хеш другой, не устанавливайте файл: скачайте пакет заново по ссылке этой страницы. Хеш ZIP опубликован рядом с архивом и отличается от хеша PAK.

Наличие общедоступного архива не означает разрешения перепубликовывать или продавать его: делитесь ссылкой на официальный релиз.
