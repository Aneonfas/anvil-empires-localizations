## Installation

1. Beende das Spiel. Wähle in **Steam → Eigenschaften → Sprache** die Sprache **English** und warte, bis alle Downloads abgeschlossen sind.
2. Öffne über **Verwalten → Lokale Dateien durchsuchen** den Ordner **`Anvil\Content\Paks`**.
3. Deaktiviere andere Sprachpakete, indem du `.disabled` an deren Dateinamen anhängst. Sichere ältere Versionen unter freien Namen, ohne vorhandene Sicherungen zu überschreiben.
4. Entpacke das ZIP und kopiere **nur `Anvil-German-Full_P.pak`** nach `Paks`. Starte das Spiel.

**Es darf nur ein Sprachpaket aktiv sein. Verändere oder lösche niemals die Spieldatei `Anvil-Windows.pak`.**

## Aktualisieren und entfernen

Wiederhole zum Aktualisieren die Installation. Zum Deaktivieren das Spiel beenden und `.disabled` an `Anvil-German-Full_P.pak` anhängen. Zum Entfernen nur diese Datei löschen. Für die Rückkehr zu einer älteren Version das neue Paket deaktivieren und den ursprünglichen Dateinamen der Sicherung wiederherstellen.

## Bekannte Einschränkungen

Orts- und Fraktionsnamen bleiben erhalten. Servermeldungen, Text in Bildern und weitere Texte können englisch bleiben. Datums-, Zahlen- und bestimmte Pluralformate folgen weiterhin englischen Regeln. Das Paket verwendet die Spielschriften ohne Ersetzungen.

Bei Problemen das Paket vorübergehend deaktivieren und Version, betroffenen Bildschirm sowie Schritte zur Wiederholung auf der [Problemseite](https://github.com/Aneonfas/anvil-empires-localizations/issues) melden.
